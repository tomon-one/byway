Знак byway в растре
===================

Что это. Каирн -- стопка камней, которой метят тропу там, где её не видно.
Отсюда и название: byway -- это тропа в обход, а знак говорит, что она
размечена.

Зачем папка. SVG принимают не везде: превью репозитория на GitHub, аватар,
вставка в форум или статью хотят PNG. Держать растр отдельно от вектора нельзя
-- копии разъедутся молча, поэтому все файлы здесь СОБРАНЫ из ../logo.svg и
руками не правятся.

  byway-1024.png             прозрачный фон, для чего угодно
  byway-512.png              аватар организации
  byway-256.png              аватар, README, статья
  byway-128.png
  byway-64.png               значок вкладки, список пакетов
  byway-social-1280x640.png  превью ссылки на GitHub (Settings -> Social preview)

Пересобрать после правки знака:

  python3 scripts/pc/logo-png.py

Вектор лежит на уровень выше и остаётся источником правды:

  logo.svg        основной знак, 64x64
  logo-flat.svg   силуэты без объёма, для 16-32 пикселей
  logo-wide.svg   широкая версия со словом byway, для шапки README

⚠️ Широкой версии в растре здесь НЕТ намеренно: в ней есть текст, а текст без
того же шрифта отрисуется другим. Лучше отдать её вектором, чем растром,
который врёт.
